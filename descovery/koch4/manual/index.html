Koch 4 本（握手 2 ペア・VR）マニュアル

小型ロボットアーム Koch v1.1 を 4 本（リーダー 2・フォロワー 2）使う展示の手引きです。握手の体験と、ゴーグルを着けて仮想の物を握る体験を、同じ Mac から起動します。

このページは入口です。握手の配線と当日の流れは 握手のページ、遊び方と電源は VR のページ、Meta アカウントの作り方からゴーグルを Mac に繋ぐまでは Quest の準備のページ にあります。

0. できること

握手（2 ペア）

説明員がリーダーを握ると、離れた机のフォロワーが同じ動きをします。来場者がフォロワーの手を握ると、その握る力がリーダーの指に返ります。

./koch4/start.sh handshake

VR（1 人）

ゴーグルを着けたままリーダーを握ると、目の前の同じ位置に仮想の物（スポンジ・ボール・鉄ブロック）が見えます。握ると硬さと重さが手に返り、投げられます。

./koch4/start.sh vr

VR（2 人）

同じペアのフォロワー機も手で握る入力装置にします。2 本の腕が同じ仮想の机に並び、物を取り合ったり渡したりできます。

./koch4/start.sh vr2

1. 全体図

2. 最初の 1 回だけ（Mac の準備）

  1. リポジトリを取得して依存を入れる。 
    git clone https://github.com/rnohmoto/twinarm.git
cd twinarm/descovery
uv sync
    既に取得済みなら git pull の後に uv sync。
  2. 腕に触れない確認をする。制御則の自己診断、準備状況（握手・VR・2 人のうち起動できるもの）、見えているポートの一覧、Quest の接続状態が出ます。VR のページに要る描画ライブラリもここで取得します（ネット接続が要るのはこの 1 回だけ）。 
    ./koch4/start.sh check
  3. 設定ファイルを作り、check で出たポートを書く。ポートは自動では選びません（取り違えると別の腕が動くため）。 
    uv run python koch4/koch4_dual_launch.py --init      # koch4/config/koch4_config.json ができる
  4. 較正ファイルを確かめる。koch4/config/calibration/koch_leader/ と koch_follower/ に、設定ファイルの id と同じ名前の JSON が要ります（ペア A・B の 4 つは同梱済み）。
  5. もう一度 ./koch4/start.sh check を実行し、「起動できるもの」に ✓ が付くことを確かめる。
  6. 腕を繋ぐ前に、ソフトの通り道だけ先に確かめられます。仮想のサーボで握手・VR・2 人・無線を起動から終了まで通します（腕は動きません。約 3 分）。 
    ./koch4/start.sh rehearse
関門 2: ./koch4/start.sh check が「selftest OK」を表示し、「起動できるもの」の握手と VR に ✓ が付く。

3. 起動早見表

コマンドは twinarm/descovery で実行します。握手と VR は腕が動くので、腕の周りに物が無いことを確かめてから起動します。

やりたいことコマンド動くもの・開く画面
握手（2 ペア）./koch4/start.sh handshakeリーダー 2・フォロワー 2。パネル http://127.0.0.1:8780
握手（ペア A だけ）./koch4/start.sh handshake --pair Aリーダー A・フォロワー A。ペア B を VR に使う日の形
握手の受け側（2 台目の Mac）./koch4/start.sh host A ＜ポート＞フォロワーを無線で受ける。操作者側に書く宛先も表示する
VR（1 人）./koch4/start.sh vrリーダー B だけ（フォロワーは繋がなくてよい）。約 12 秒後に Quest のブラウザでページが開く
VR（2 人）./koch4/start.sh vr2リーダー B とフォロワー B（手で握る）。分身が 2 体
VR の画面だけ確認（実機なし）./koch4/start.sh simMac のブラウザに模擬の腕 2 本と物体
Quest を繋ぎ直した./koch4/start.sh quest接続を張り直してページを開く
Quest を充電しながら使う./koch4/start.sh wifi接続を Wi-Fi に切り替え、USB の口を充電器に空ける
確認だけ（腕は動かない）./koch4/start.sh check自己診断・準備状況・ポート・Quest の接続と電池残量
腕なしの通し稽古./koch4/start.sh rehearse仮想のサーボで握手・VR・2 人・無線を通す。腕は動かない

握手（ペア A）と VR（ペア B）を同時に動かすときは、端末を 2 つ開いて ./koch4/start.sh handshake --pair A と ./koch4/start.sh vr をそれぞれ実行します。片方を止めても、もう片方は続きます。

VR に使うペアは既定で B です。A にするときは VR_PAIR=A ./koch4/start.sh vr。握手でフォロワーの握力の上限を変えるときは GRIP_MA=400 ./koch4/start.sh handshake。コマンドの後ろに書いた指定はそのまま起動の本体に渡ります（例: ./koch4/start.sh handshake --follower wired）。

起動してすぐ止まったときは、端末に | で始まる行（記録の末尾）が出ます。そこに理由が書かれています。

4. 止め方

  1. 腕を机に寝かせる（止めると腕の力が抜けて落ちます）。
  2. 起動した端末で Ctrl+C。全部の処理が止まるまで数秒待つ。
  3. 全アームの AC アダプタを抜く（通電したままにするとサーボが熱を持ちます）。

5. どのファイルが何か

ファイル役割
koch4/start.sh起動の入口（上の早見表）
koch4/config/koch4_config.jsonペアごとのポート・id・無線フォロワーの宛先（各 Mac で作る。共有しない）
koch4/config/koch4_twin.jsonVR の分身の位置・関節の対応・物体の硬さと重さ（VR の画面から保存される）
koch4/config/calibration/腕ごとの較正（関節の原点と可動範囲）
koch4/work/logs/各処理の記録。うまく動かないときに見る
koch4/koch4_dual_launch.py2 ペアと VR をまとめて起動・停止する本体
koch4/koch4_teleop.py1 ペアの制御（追従・握り返し・仮想の壁と重さ）
koch4/koch4_follower_host.py握手の机の Mac で動かす受け側（無線フォロワー）
koch4/koch4_vr_bridge.py・koch4/webxr/index.htmlVR の画面を配信する側と、ゴーグルで開くページ
koch4/koch4_quest_usb.pyQuest を USB（または Wi-Fi）で繋いでページを開く
koch4/simbus/腕なしの通し稽古（仮想のサーボと、その検査）
koch4/CHECKLIST.md実機で順に確かめる手順と記録欄

6. 安全

  • 起動の前に、腕の可動範囲（半径 40 cm）に顔・飲み物・ケーブルが無いことを確かめる。
  • 握り返しや重さが出ている間は、リーダーから手を離さない（手を離すと腕が動くことがあります）。
  • フォロワーが赤い表示で止まったら（過負荷）、AC アダプタを 10 秒抜いて入れ直す。
  • サーボは 60°C で力を弱め、65°C で力を止めます。体験 1 回ごとに少し休ませる。
  • VR 2 人のとき、フォロワー機は起動直後に腕の力が抜けます。手で支えてから起動する。
  • 終わったら必ず AC アダプタを抜く。
