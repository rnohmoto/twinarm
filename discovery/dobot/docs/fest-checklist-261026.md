## 1. 設営（10 分）

- ロボットと物は **同じ面（机）** に載せる。高さ（z）はロボットの基部からの相対なので、会場が変わっても測り直さなくてよい
  （マットを敷くなら、物の下だけでなく全部をマットの上に。ロボットだけ机・物だけマットだと、マットの厚みぶん押し付ける）
- カメラは真上（三脚・高さ 45〜50 cm）。作業域＝ロボットの前 15〜30 cm・左右 ±15 cm が画面の中央
- Logi Options+: オートフォーカス OFF（机にピント）・自動露出 OFF・ホワイトバランスは自動（Mac は起動のたびに書き直す）
- 白いボールを使うなら **濃い色のマット** が必須。白い紙・マーカー・白いトレイを作業域に置かない
- 較正用に青ブロック 1 個をすぐ出せる所に

## 2. 立ち上げ（5 分）

1. Magician の電源 ON → 本体キー 2 秒長押し（LED 青点滅 → 緑）。**電源を入れるたびに必要**（初代はホーミングしないと座標が狂う）
2. カメラと Magician の USB を Mac に挿す。腕の周りを空ける
3. `scripts/start.command` をダブルクリック → ランチャー（http://127.0.0.1:8789）
4. ランチャーの「カメラ確認」で 1 枚 → 作業域が入っているか・ピントが合っているか
5. ランチャーの「較正: 日時・RMS・点数」を見る（10/19 12:38・9 点・RMS 3.10 が入っている）

## 3. 較正は要るか（30 秒〜1 分）

**カメラかロボットを動かしていなければ不要。** 動かした（三脚を立て直した・ロボットを置き直した）なら:

1. 青ブロックを 1 個、カメラに見える所（トレイの外・作業域の中）に置く → ランチャー **「較正を確認」** → Terminal が開く
2. 腕がそれを拾い、中心に置き、ずれを測る（約 30 秒）
   - 「較正は使えます: ずれ x mm」→ **そのまま使う**（やり直し不要）
   - 「拾えませんでした」「ずれ > 3 mm」→ 3 へ
3. 机からトレイをどけ、青ブロックを 1 個用意 → **「較正をやり直す」** → 腕が最初の点（右手前の隅）の上 8 mm で止まる →
   **吸盤の真下にブロックを置いて Enter（これ 1 回だけ）** → 腕が運んで 9 点を回る（約 1 分）→ `RMS=… mm`
   - 3 mm 以下で合格。超えたらカメラの固定（AF・露出）とブロックの置き方を見てもう 1 回
   - 「見えません」「落ちた？」と聞かれたら: ブロックを吸盤の真下に置いて Enter（3 回で飛ばす・q で中断＝4 点以上なら保存）
   - Terminal を使わない予備: `uv run dobot-calibrate --config src/config.json --object blue_cube --carry --points quick`（5 点・40 秒）

なぜ 9 点か: 画素 → 座標の変換（ホモグラフィ）は 4 点で決まる。5 点で足り、9 点は余りの点で当てはまりの悪さ（RMS）が見える。
端まで広く取るのは精度のためで、可動域を調べているのではない。

## 4. 置き場（1 分・腕は動かない）

トレイを置いたら **「置き場を調整」** → 画像に丸が出る → 数字（1〜5）で選び、実物のトレイの真ん中をクリック → s で保存 → q。
置く位置が作業域の外なら拒否されるので、少し内側へ。ロボットの「右」は画面の左。

## 5. 1 回動かす（2 分）

1. **「実演を起動」**（腕がホームへ）→ 実演画面（http://127.0.0.1:8790）
2. 「往復（試運転）」→ 動作中に「非常停止」が効くことを 1 回見る → 「停止解除」→「ホーム」
3. 文字で「赤いブロックを右に置いて」→ 声で 1 回（「声の準備ができました」が出てから）
4. 落とす・止まる・アラーム → [HANDOFF §6](HANDOFF.md) の順に戻す: 速さ 100 → 70、吸着の待ち 0.4 → 0.6、z_safe 20 → 40

## 7. 連続運転と熱

- 速さ 100 % で 1 回 7 秒。脱調（J1〜J4・0x50〜53）のアラームが出たら 70 % へ
- 動作は 10 分のうち 4 分まで（熱の予算）。自動ループは既定 OFF。超えると自動動作が 2 分休む
- アラームの復帰: 範囲系（届かない・限界）は自動で解除され「停止解除」→「ホーム」で続けられる。**脱調は違う**: 公式の復帰条件は
  ホーミング（回零）なので、腕の周りを空けて **本体キー 2 秒長押し**（J1 が左右に振れる・LED 緑まで待つ）→「停止解除」→「ホーム」。
  パネルの「ホーム」は座標へ動くだけで基準を取り直さない。原因（引っかかり・速すぎ）も見る
- 置き直しや動きがおかしいときもホーミングからやり直す。ホーミングで座標の基準が戻るので較正はそのまま使える

## 8. 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「拾えませんでした」が続く | 吸着の待ち 0.6・ブロックの上面が汚れていないか・`z_pick` が上面 −1 になっているか（`dobot-setup --from 6`） |
| 較正の RMS が 3 mm を超える | カメラの AF が戻っていないか（Logi Options+）・三脚の揺れ・ブロックが吸盤の真下からずれて置かれた → もう 1 回 |
| 色が拾えない | 照明が変わった。ブロックを影の無い所へ。直すなら `objects[].ranges`（`dobot-setup --from 7` で見ながら） |
| 「届きません」 | 物と置き場をロボットから 15〜30 cm の中へ。画面の「x」印は届かない物 |
| 画面が固まる | ランチャー「再起動」。駄目なら Terminal で Ctrl+C → `start.command` |
| ポート使用中 | 前の実演が残っている → ランチャー「停止」、または `pkill -f dobot.demo` |
