# Koch4 VR 体験 — 要件定義書（2026-10-19 版）

実機の Koch アームを手で動かし、ゴーグル（Meta Quest Pro）の中の仮想の物を握る体験の、要件と設計判断。
2026-10-19 の実機セッション（Quest Pro 初接続）で判明した事実を前提に書き直したもの。
起動と操作の手引きは [`manual/vr.html`](manual/vr.html)、実機の手順と記録欄は [`CHECKLIST.md`](CHECKLIST.md)、
引き継ぎは [`HANDOFF.md`](HANDOFF.md)、10/19 の記録は [`LOG_261019_VR.md`](LOG_261019_VR.md)。

「確認済み」= 実機で確かめた。「判断」= Claude が決めた点（ユーザーの指示ではない）。

## 1. 体験（何を見せるか）

- 来場者がゴーグルを被り、目の前の実機アーム（リーダー B）を手で動かして、机の上の仮想の物
  （スポンジ・ボール・鉄ブロック）を握る。握ると硬さ（グリッパの壁）と重さ（肩・肘の電流）が手に返る。
  放すと落ちる・跳ねる。同じ色の丸に置けたら音が鳴る（置く的）。
- **2 人**: 1 人目はリーダー B（MacBook Pro 1 ＋ Quest Pro #1）、2 人目はフォロワー B を手で動かす
  （MacBook Pro 2 ＋ Quest Pro #2）。それぞれ自分の空間・自分の主観で握る。Mac 同士の通信は無い。
- 観客は Mac の画面（観客ページ）で見る。

## 3. 機能要件

| # | 要件 | 状態 |
| --- | --- | --- |
| FR-1 | **1 クリック起動**: Finder で `.command` をダブルクリックするだけで、依存の同期（uv）→ VR ページの部品 → 設定ファイル（無ければ fest 設定から作る）→ ポートの解決（USB シリアル番号）→ ブリッジ → teleop → Mac の操作ページ → Quest の許可待ち → adb reverse → ゴーグルでページを開く、まで進む。別の Mac に clone しても、初回のネット接続（uv sync・three.js・adb の導入）以外は同じ | 実装 10/19（判断）。実機は Mac 1 で確認、Mac 2 は未 |

| FR-5 | **設定の即時反映**: Mac で保存した設定（高さ・置き場所・物の硬さ）は、ゴーグルのページが 1 秒以内に読み直す（再読込なし・AR 継続） | 実装 10/19（判断） |
| FR-6 | **Quest の接続維持**: USB が再列挙されて reverse が消えても、2 秒以内に張り直し、ページは開いたまま復帰する。許可（USB デバッグ）が未だなら待つ | 確認済み 10/19（見張りスクリプトで 2 回自動復帰）→ `quest_usb.py --watch` に実装 |

## 4. 非機能要件

- 起動: ダブルクリックから分身が動くまで 1 分以内（uv sync 済みの Mac）。Quest の許可済みならページも自動で開く。
- 復帰: USB 切断から 4 秒以内に reverse 復帰、AR は途切れない。ゴーグルを外して戻っても、アンカーで位置は保たれる。
- 会場: ネット不要（Quest は USB、Mac 間通信なし）。初回のみ uv sync と three.js 取得にネットが要る。
- 電池: Quest Pro は USB（Mac 給電）で約 1 時間 98→99〜100%（減らないが安定して充電もしない・10/19）。
- 記録: 各プロセスの標準出力は `work/logs/`（`solo_<腕>_vr.log`・`quest_<腕>.log`・teleop は窓に出る）。

## 5. 制約・前提（実機で判明したこと）

1. **Quest Browser は AR 中に DOM overlay を描かない**（ボタン・文字・案内が一切出ない。Meta のフォーラムで裏取り）。
   → ゴーグルの中の操作はつかむ・音・コントローラの基準点の小球と光線だけ。残りは Mac から。
2. **USB が数十分に 1 回切れる**（Quest Pro を Mac 本体の口に直結した状態で再列挙。adb の reverse が消える）。
   → 見張りで自動復帰。「常に許可」を付けておけば再許可は要らない。
3. **土台の回転（shoulder_pan）は較正 1 回転ぶん・サーボは多回転モード**。電源投入後に 1 回転以上回すと読み値が
   ±100 に張り付き、分身の土台だけ止まる。→ 逆向きに 1 回転戻す。1 回転以上ぐるぐる回さない。
4. **Quest の USB デバッグの許可は Mac とヘッドセットの組ごと**。初期化した台は許可が消える。Mac 2 でも許可を出す。
5. **空間アンカー（persistent anchors）は Quest Pro の Quest Browser で動く**（登録・復元を確認）。
6. 位置合わせ C（点取り）は、腕を動かさずに取ると向きが決まらない（10/19 に 60 点・5 点で不成立）。
   コントローラの基準点は光線の起点で、握りの右下に出る。→ つかんで動かす方式を本命にした。

## 6. 設計判断（判断）

- **起動の正本は `scripts/koch.sh`**（`.command` はその呼び出し）。`scripts/start.sh vr` も残すが、Quest の見張りと操作ページは `koch.sh` 側だけ。
- **ブリッジに操作キュー `/op` と状態報告 `/status`** を足し、`/state` に `op`・`page`・`cfg_version` を載せる。ページはこれだけ見て動く（adb や DevTools に依存しない）。開いた時点より前の操作は実行しない。
- **操作ページ＝同じ VR ページの観客モード＋文字**（`?spectator=1&info=1`）。接触を送らず、ゴーグルのページに操作を送る。
- **fest 設定 `config/config.fest.json`** を git に入れ、Mac ごとの `config.json` が無ければ写す。ポートはシリアル番号で解決する（`koch.sh` が pyserial で現在の名前を探す）。
- **物が乗る面の高さ `scene.desk.y`** を設定に追加（既定 0、フェスの設定ファイルは 0.04）。物理の床・的・置き場所がその面に乗る。
- Mac からの遠隔操作の予備経路として Chrome DevTools（`quest_usb.py --devtools` で 9222 を forward、`koch4.startCalib()` など）も残す。
