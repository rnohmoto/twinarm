Dobot Magician 接続マニュアル

画像認識ピック＆プレース構成の配線と起動の手引き。端子の値は Dobot 公式の Interface Description と User Manual によります（§8）。

対象は初代 Magician（4 軸・USB シリアル・本体内蔵制御器）。Magician Lite（Magic Box 付き）と E6（6 軸・Ethernet）は端子が異なり、このページの表は当てはまりません。

0. 全体図

2. 接続と起動（この順で・電源は最後）

  1. 置く: 本体を机の奥中央に置き、作業域（前方に半径 32cm）に物が無いことを確認する。土台を養生テープかクランプで固定する。
  2. 電源が切れていることを確認してから配線する（SW と GP の抜き挿しは必ず電源を切って行う）。
  3. 吸盤（またはグリッパ）を前腕先端に取り付け、チューブをポンプボックスに繋ぐ。
  4. ポンプボックス: 電源線を背面 SW1、信号線を背面 GP1 に挿す（User Manual の指定）。グリッパキットも同じポンプボックスを使う。
  5. USB ケーブル: 本体背面の USB から PC へ。ハブを使うならカメラと別の口が望ましい。
  6. AC アダプタを本体の電源ジャックへ。コンセントは最後に挿す。
  7. 電源を入れ、腕に触れずに待つ。本体のキーを 2 秒長押しすると LED が青点滅し、緑になればホーミング完了。
  8. カメラを PC の USB に挿す（§3）。
  9. 起動: PC のターミナルで次を実行する。初回は設定ウィザードが始まり、設定が済んだ後は実演画面（ブラウザ）が開く。
cd twinarm/dobot
./start.sh              # Mac / Linux（初回は uv が Python 環境を作る）
start.bat               # Windows

./start.sh wizard       # 設定をやり直す
./start.sh demo         # 実演画面だけ起動（http://127.0.0.1:8790）
./start.sh dry          # 実機を繋がずに画面だけ確認
./start.sh check        # カメラ一覧・ポート候補・テスト（読み取りのみ）

ウィザードは、カメラ → ロボット（ポートを候補から選ぶ）→ マーカー → 較正 → 置き場 → 物の高さ → 検出の確認 → 試運転、の順に進み、結果を config.json に保存します。腕が動くのは y と答えた場面だけです。個別の確認は次のコマンドでもできます。

uv run python check_robot.py --list                          # 候補ポートを表示（自動では選ばない）
uv run python check_robot.py --port /dev/tty.usbserial-XXXX  # 接続して現在位置を読む（動かない）
uv run python check_robot.py --port /dev/tty.usbserial-XXXX --home   # ホーム姿勢へ動く
uv run python check_camera.py --list ; uv run python check_camera.py --index 0
初代 Magician に衝突検知はありません。ホーミング中と動作中は作業域に手を入れない。止めるときは電源スイッチ。電源を切るときは LED が消えるまで待つ（腕がゆっくり所定位置へ動いてから止まる）。
関門: LED が緑、PC にポートが見える、--home でホーム姿勢へ動いて止まる、check_camera.py が「手動露出が効いています」と「明るさは安定しています」を出す。

3. カメラの接続

  • PC の USB 2.0 以上の口に直接繋ぐ。ケーブルは 3m 以内（延長するならアクティブケーブル）。
  • Magician と同じ USB ハブは避ける。カメラを 2 台にするときは別系統に分ける。
  • 取り付けは 1/4-20 ネジ（クリップの三脚穴かマジックアーム）。高さ 45cm で真下向き。詳細は初期設定マニュアル §3。
  • 露出・ホワイトバランス・オートフォーカスの固定は check_camera.py で確認する。Mac で固定できない場合は Logi Tune か OS の設定で固定する。

ポートは自動では選びません（誤った機器に指令を送らないため）。ウィザードが config.json の robot.port と camera.index に書き込み、以後の起動で引数が要らなくなります。

5. 温度センサの接続（任意）

  1. サーミスタ（3D プリンタ用 NTC 100kΩ・ケーブル付き）の先端を J1（土台）モーターの筐体にカプトンテープで密着させる。
  2. 電源を切った状態で、サーミスタの 2 線を Temp（EIO1）と GND に挿す（デュポンワイヤ）。
  3. ADC のフルスケール電圧を確かめる。何も繋がない状態で check_robot.py --port … --adc 1 を実行し、読み値が 4095 付近なら 3.3V、2700 付近なら 5V。後者なら config.json の demo.temp_adc_fullscale_v を 5.0 にする。
  4. サーミスタを繋いで check_robot.py --port … --temp 1 を実行すると温度が表示される。室温と放射温度計の値が合うことを確かめる（ずれるなら demo.temp_beta を調整）。
  5. config.json の demo.temp_eio を 1 にすると、実演画面に温度が出て、60℃ 以上で自動動作（ループ・自動ループ）が休止し、50℃ 未満で再開する（しきい値は demo.temp_stop_c／temp_resume_c）。

サーミスタの正式な抵抗値と B 定数は Dobot の公式資料にありません（プルアップの設計から 100kΩ 系と判断）。放射温度計（購入リスト B2）で実測しておけば、換算のずれはその場で直せます。

6. 吸着の成否と電流（任意）

初代 Magician は、モーターの電流・トルク・負荷を返しません（通信プロトコル、API 説明書、公式 DLL のいずれにも該当コマンドがありません）。あるのは脱調検知（位置誤差のしきい値）だけです。関節ごとの電流・トルク・手先負荷を返すのは MG400 や CR 系（E6 も同系列）の TCP/IP フィードバックです。
見たいもの方法接続備考
吸えたか（ピックの成否）負圧センサ（−100〜0kPa・アナログ 0.5〜4.5V・5V 電源）を吸盤の配管に T 継手で割り込ませるセンサ出力 → 空きの GP（ADC・最大 5V）、電源 → GP の 5V（20mA 以内）、GND純正吸盤キットに真空センサは無い。±2kPa の差圧センサや正圧用センサは範囲が合わない
腕全体の負荷の目安12V 供給線の電流を見る（バレルジャック割り込み型の DC 電力計、または ACS712 モジュール）ACS712 は出力 → GP（ADC）、電源 5V、GND。電力計は表示を読むだけ関節ごとには分解できない。物を持ったとき・ぶつかったときの増分を見る用途
ぶつかった（脱調）SetLostStepParams（既定のしきい値 5）と SetLostStepCmdソフトのみ各軸の脱調アラームで分かる。衝突の瞬間に止まる保証は無い

7. 困ったとき（接続まわり）

症状まず疑う手当て
PC にポートが出ないケーブルが充電専用、CP210x ドライバ、電源が入っていない付属ケーブルに戻す、ドライバを入れる、電源を入れる
LED が赤リミット到達かアラーム未解除電源を入れ直してホーミング。続くなら DobotStudio でアラームを解除する
ポンプが動かない・吸わないSW1（電源線）と GP1（信号線）の挿し違い、チューブ外れ、吸盤ゴムの劣化電源を切って挿し直す。チューブとゴムを点検する
吸着が弱い物の上面が多孔・小さい・凸凹、z_pick が浅い対象物を変える（購入リスト A4〜A6）。z_pick を 1〜2mm 深くする
動作中に USB が切れるケーブルの取り回し、ハブの電源ケーブルを固定する。ハブを外して直挿しにする。再接続後にホーミング
温度が「範囲外」サーミスタ未接続か短絡、フルスケール電圧の設定違い§5 の手順 3〜4 をやり直す
