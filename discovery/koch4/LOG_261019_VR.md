## 2. 分かったこと（事実）

1. **Quest Browser は immersive-ar で DOM overlay を描かない**。ページの UI（ボタン・HUD・位置合わせの案内）は一切見えない。`select`（トリガー／つまむ）は届く。
2. **位置合わせ C は腕を動かさずに取ると向きが決まらない**（q が全点同じ）。コントローラの基準点は光線の起点で、握りの右下に出る。
3. **shoulder_pan の較正は 0〜4095（1 回転）、サーボは多回転モード**。電源投入後に 1 回転以上回すと ±100 に張り付く。逆向きに 1 回転で復帰。
4. **空間アンカーは Quest Pro で動く**: `requestPersistentHandle` → localStorage → 次の AR で `restorePersistentAnchor`。再 AR・2 時間後の再接続で復元を確認。付け替え・境界の引き直しは未確認。
5. **Quest の USB は数十分に 1 回切れる**（Mac 本体の口に直結・Fresco Logic のハブとは別）。再列挙で adb の reverse が消える。「常に許可」を付けておけば再許可は要らない。
6. 電池: USB（Mac 給電）で 1 時間 98→99〜100%。`dumpsys battery` は充電中／放電中が入れ替わる。
7. 置き場所 22〜27 cm・机の面 0 では「地面より下じゃないと掴めない」（ユーザー）。
