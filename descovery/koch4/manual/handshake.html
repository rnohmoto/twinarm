Koch 握手マニュアル（2 ペア）

説明員がリーダーを握ると、離れた机のフォロワーが同じ動きをし、来場者がフォロワーの手を握ると、その力がリーダーの指に返ります。2 組を同時に動かします。

リーダーは操作する机の Mac に USB で繋ぎ、フォロワーは握手の机の Mac に繋いで、2 台の Mac の間を自前の 5 GHz ルータで結びます。フォロワー側にケーブルを這わせないための構成です。

0. 全体（何が何に繋がるか）

1. 用意する物

物数条件
Mac（操作者側）1入口のページ §2 の準備が済んでいること
Mac（握手用）1同じ準備。バッテリーで動かせるので、握手の机の電源はアームの 12V だけで済む
Koch リーダー25V の AC アダプタ。較正済み
Koch フォロワー212V の AC アダプタ。較正済み。握手用の手の部品を付ける
5 GHz のルータ12 台の Mac だけを繋ぐ。インターネットは不要
USB ケーブル（データ対応）4アームの基板の口は USB-C で、通信は USB 2.0 です。USB 2.0 用のデータ対応ケーブルで足り、長くするなら 4 m の認証品までが確実です。ハブを使うなら電源付きで、4 口ともデータ対応のもの

2. 設定（最初の 1 回）

  1. 握手用の Mac: フォロワー 2 本を USB で挿し、ポートを確かめる。 
    uv run python koch4/koch4_dual_launch.py --list
  2. 握手用の Mac: ルータに繋ぎ、IP アドレスを確かめる。 
    ipconfig getifaddr en0
  3. 操作者側の Mac: 設定ファイルを作り、リーダーのポートと、握手用の Mac の宛先を書く。 
    uv run python koch4/koch4_dual_launch.py --init
# koch4/config/koch4_config.json の例（ペア A）
#   "leader_port":   "/dev/tty.usbmodem＜リーダー A＞",
#   "follower_host": "udp://＜握手用 Mac の IP＞:9101",
#   "follower_port": "/dev/tty.usbmodem＜有線に戻すときのフォロワー A＞"
# ペア B は 9102

どのアームをどの口に挿すかは、テープで印を付けて固定します。挿す口を変えるとポートの名前が変わることがあります。

3. 起動（毎回）

  1. 4 本とも腕を机に寝かせ、AC アダプタを挿す（リーダー 5V・フォロワー 12V）。
  2. 握手用の Mac で受け側を 2 つ起動する（端末を 2 つ開く）。 
    cd twinarm/descovery
./koch4/start.sh host A ＜フォロワー A のポート＞
./koch4/start.sh host B ＜フォロワー B のポート＞
    起動すると、操作者側の設定ファイルに書く宛先（この Mac の IP と番号）が表示されます。ポートは uv run python koch4/koch4_dual_launch.py --list で確かめて渡します。
  3. 操作者側の Mac で起動する。 
    cd twinarm/descovery
./koch4/start.sh handshake
    フォロワーが 1.5 秒かけてリーダーの姿勢に合流し、パネルがブラウザで開きます。ペア A だけで握手する日は ./koch4/start.sh handshake --pair A（ペア B を VR に使っていても同時に動かせます）。
  4. リーダーを動かし、フォロワーが付いてくることを 2 組とも確かめる。
関門 3: 片方のリーダーを動かしたとき、動くのは同じ組のフォロワーだけ（もう片方が動いたらポートの取り違え）。フォロワーの指で物を握ると、リーダーの指が押し返される。

4. パネル（http://127.0.0.1:8780）

1 枚の画面に 2 組の状態が並びます。スライダとボタンは 2 組に同じ値で効きます（1 組ずつ変えることはしません）。

表示・操作意味
握り上限 mAリーダーの指に返す力の上限。上げると強く押し返すが、熱を持ちやすい（既定 450）
ゲインフォロワーが握った力を、どれだけ強くリーダーに返すか
モード OFF／gripper握り返しの入・切
合流フォロワーをリーダーの姿勢にゆっくり合わせ直す
赤い札注意の表示（§7 の表）
遅延・欠落無線の状態。遅れが 0.3 秒を超えると赤い札が出る

5. 無線が切れたとき・有線に戻すとき

無線の途切れフォロワーの動き
0.3 秒パネルに赤い札「フォロワー無線 遅延」
0.5 秒その場の姿勢を保つ（力は入ったままなので腕は落ちない）
3 秒操作者側が通信断と判断し、自動で繋ぎ直す
復帰1.5 秒かけてリーダーの姿勢に滑らかに戻る

無線が安定しないときは、フォロワーを操作者側の Mac に USB で繋ぎ替えて、有線で起動します。設定ファイルは同じものを使えます。

./koch4/start.sh handshake --follower wired

6. 握る物と握力

  • フォロワーの握る力には上限（--grip-ma・既定 500 mA）を掛けています。上限が無いと、物を握ったままサーボが力を出し続けて過負荷で止まり、物を落とします。
  • 握力が足りないときは 600、700 と上げ、止まりやすいときは 400、350 と下げます。操作者側は GRIP_MA=400 ./koch4/start.sh handshake、握手用の Mac は GRIP_MA=400 ./koch4/start.sh host A ＜ポート＞。
  • 物を持たせるなら、卓球ボール（直径 40 mm）が安全です。ゴルフボールは重さと滑りやすさで限界に近く、落としやすくなります。指先に滑り止めのテープを貼ると持ちやすくなります。
  • 動きを穏やかにするには --extra "--max-rel 15" を付けて起動します（1 回に動く量の上限。既定 20）。

7. 困ったとき

症状・赤い札確かめること・直し方
起動時に「ポートが存在しません」--list で今のポート名を確かめ、設定ファイルを直す。挿す口を変えていないか
起動してすぐ「…が終了しました」と出るすぐ下に | で始まる行（記録の末尾）が出る。そこに理由が書かれている
「較正が、サーボ内の値とファイルで一致しません」ポートの取り違え（A と B、リーダーとフォロワー）か、較正をやり直した後にファイルを入れ替えていない。設定ファイルのポートと id を確かめる。腕の中の値は書き換えずに止まっている
フォロワーが動かない握手用の Mac の受け側が動いているか。宛先の IP と 9101／9102。2 台が同じルータにいるか
「…gripper エラー停止（過負荷）」そのアームの AC アダプタを 10 秒抜いて入れ直す。繰り返すなら握力の上限を下げる
「フォロワー握力が上限付近」滑る・止まる前ぶれ。物を軽くするか、深く持たせる
「握り反力が上限に張り付き」握り込みを緩める
「…°C」サーボが熱い。60°C で力を弱め、65°C で握り返しを止める。体験の合間に休ませる
「通信断 → 再接続中」USB の接触。手を離して 2 秒待つ。続くならケーブルとハブの電源
握っても押し返さない起動時の表示に Operating_Mode=5 / Position_P_Gain=800 が出ているか。パネルのモードが gripper か
リーダーとフォロワーの姿勢が合わない両方の腕を同じ姿勢に手で持ち、ずれを数値で見る。3% を超える関節は較正をやり直す 
uv run python koch4/koch4_calib_offset.py --leader-port ＜L＞ --follower-port ＜F＞ --leader-id koch_leader_A --follower-id koch_follower_A

8. 安全

  • 来場者にはフォロワーの「手」だけを握ってもらう。腕の根元や関節には触れさせない。
  • 握り返しが出ている間、説明員はリーダーから手を離さない。
  • フォロワーが止まったら（過負荷）、腕を支えてから AC アダプタを抜き差しする。
  • 終わったら Ctrl+C（操作者側 → 握手用の順）で止め、4 本とも AC アダプタを抜く。止めるとフォロワーの力が抜けるので、先に腕を寝かせる。
