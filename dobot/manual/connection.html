Dobot Magician 接続マニュアル（v1・2026-09-20）

何を・どこに・どの順で繋ぐか。端子の値は Dobot 公式の Interface Description（旧版・V2）と User Manual V1.2.4 で確認したもの（★）。現物で確認すべき点は「要現物確認」と書いた。

対象は初代 Magician（4 軸・USB シリアル・本体内蔵制御器）。Lite（Magic Box 付き）・E6（6 軸・Ethernet）は端子が違うので、このページの表は使えません。

2. 接続手順（この順で・電源は最後）

  1. 置く: 本体を机の奥中央に置き、作業域（前方 半径 32cm）に物が無いことを確認。土台を養生テープかクランプで固定。
  2. 電源 OFF を確認してから配線する（SW／GP の抜き挿しは必ず電源 OFF で）。
  3. 吸盤（またはグリッパ）を前腕先端に取り付ける（付属のネジ）。チューブをポンプボックスへ。
  4. ポンプボックス: 電源線 → 背面 SW1、信号線 → 背面 GP1（★User Manual）。グリッパキットも同じポンプボックスを使う。
  5. USB ケーブル: 本体背面 USB → PC。ハブを使うならカメラと別の口が望ましい（1 台ずつなら同じハブでも可）。
  6. AC アダプタを本体の電源ジャックへ。コンセントは最後に。
  7. 電源 ON → 腕に触れずに待つ → 本体のキーを 2 秒長押し（LED 青点滅 → 緑でホーミング完了）。
  8. PC でポートを確認（§4）→ check_robot.py --list → --port を指定して接続（動かない）→ --home（動く）。
  9. カメラを USB に挿す（§3）→ check_camera.py --index 0。
初代 Magician に衝突検知はありません。ホーミング中と動作中は作業域に手を入れない。止めるときは電源スイッチ。電源を切るときは LED が消えるまで待つ（腕がゆっくり所定位置へ動いてから止まる）。
関門: LED 緑・PC にポートが見える・check_robot.py --port … --home でホーム姿勢へ動いて止まる・check_camera.py が「手動露出が効いています／明るさは安定しています」を出す。

3. カメラの接続

  • PC の USB 2.0 以上の口に直接。ケーブルは 3m 以内（延長するならアクティブケーブル）。
  • Magician と同じ USB ハブは避ける（1 台ずつなら支障は出にくいが、切り分けが楽）。カメラを 2 台にするときは別系統に分ける。
  • 取り付けは 1/4-20（クリップの三脚穴 or マジックアーム）。高さ 45cm・真下向き。詳細は初期設定マニュアル §3。
  • 露出・WB・AF の固定は check_camera.py で確認。Mac で効かない場合は Logi Tune（対応機種なら）か OS 側で固定。

5. 温度センサの接続（任意・B3〜B5）

  1. サーミスタ（3D プリンタ用 NTC 100kΩ・B≈3950・ケーブル付き）の先端を、J1（土台）モーターの筐体にカプトンテープで密着させる。次に J2・J3 も同様（増やすなら GP の ADC 入力を使う）。
  2. 電源 OFF で、サーミスタの 2 線を Temp（EIO1）と GND に挿す（デュポンワイヤ。コネクタ形状は現物で）。
  3. ソフト側は SetIOMultiplexing(EIO1, ADC) → GetIOADC（コマンド ID 134・12bit）で読む。pydobot には無いので robot_dobot.py に追加する（未実装・依頼があれば 1 時間）。
  4. 換算は 2 点で較正する（室温と 50℃ 程度のお湯にサーミスタを入れ、放射温度計の値と合わせる）。
  5. パネルに温度を出し、熱の予算に「60℃ で自動動作を休止・50℃ で再開」のような温度基準を重ねる。

サーミスタの正式な抵抗値・B 定数は Dobot の公式資料に記載がありません（4.7kΩ プルアップの設計から 100kΩ 系 NTC と推定）。まずは放射温度計（B2）で実測し、サーミスタは記録を自動化したくなってからで十分です。

6. 吸着の成否と電流（任意・C1〜C3）— トルクは見られるか

初代 Magician は、モーターの電流・トルク・負荷を返しません（★通信プロトコル V1.1.5・API Description V1.2.2・DobotDll.h の 3 ソースとも該当コマンド無し）。あるのは脱調検知（SetLostStepParams の位置誤差しきい値）だけです。関節ごとの電流・トルク・手先負荷がフィードバックで取れるのは MG400／CR 系（E6 も同系列）の TCP/IP です。
見たいもの方法接続備考
吸えたか（ピックの成否）負圧センサ（−100〜0kPa・アナログ 0.5〜4.5V・5V 電源）を吸盤の配管に T 継手で割り込ませるセンサ出力 → 空きの GP（ADC・最大 5V）、電源 → GP の 5V（20mA 以内）、GND純正吸盤キットに真空センサは無い（★）。国内の入手先は要選定（Amazon.co.jp 上位の MPXV7002 は ±2kPa で不可、秋月の MPX5700DP は正圧用）
腕全体の負荷の目安12V 供給線の電流を見る（DC 電力計をバレルジャックに割り込ませる／ACS712 モジュール）ACS712: 出力 → GP（ADC）、電源 5V、GND。電力計: 表示を読むだけ関節ごとには分解できない。物を持ったとき・ぶつかったときの増分を見る用途
ぶつかった（脱調）SetLostStepParams(threshold)・SetLostStepCmd（既定しきい値 5・単位は文書に無し）ソフトのみアラーム 0x50〜0x53（各軸脱調）で分かる。衝突の「瞬間に止まる」保証は無い
