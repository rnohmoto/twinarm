借りた Quest Pro の初期化

他の人のアカウントが入っている借用機を、展示用の Meta アカウントで使えるようにし（開発者モードと USB 接続まで）、展示が終わったら貸主に戻すまでの手引きです。借用機 1 台につき 1 回行います。

新品のゴーグルや、展示用アカウントで初期設定した台は、この手引きではなく Quest の準備を使います。この手引きは、その §4 以降を借用機向けに言い直したものです。

確認済み Meta の公式ページで確かめた記述　二次情報 利用者の報告など、公式ページに無い記述　推定 文書の組み合わせからの読み

0. 流れ

なぜ初期化になるか確認済み: Meta のヘルプは、ゴーグルの所有者を変えるには出荷時設定へのリセットが必要で、リセットの後に最初にログインした人が所有者になる、と書いています。所有者（貸主）をリセットせずに外す手順は公式にありません。開発者モードのスイッチは、その台とペアリングした Meta Horizon アプリの「ヘッドセット設定」にあり、利用者の報告では追加プロフィール側のアプリには出ません二次情報。追加プロフィール案は壊さない試しなので先に 10 分だけ行い、出なければリセットします。

1. 前日までに済ませること（PC と手元）

項目内容
展示用の Meta アカウント作成済み（2026 年 10 月 14 日）。メールアドレスとパスワードを手元に置く。Quest の準備 §2
開発者の登録と確認展示用アカウントで Meta の開発者サイトにログインし、組織（チーム）を作り、アカウントの確認（SMS か支払い方法）と組織の確認を済ませる。確認に日数がかかることがあるので、ゴーグルを触る前に終える。Quest の準備 §5

2. 貸主に伝えること・確かめること

2.1 伝える 3 点

  1. ログアウトは初期化になる確認済み。貸主のアカウントを外すには出荷時設定へのリセットしかない。
  2. 本体に入っているものが消える確認済み。アカウント情報と、ダウンロード済みのゲームやコンテンツが本体から消える。購入したものはアカウントに残り、もう一度ダウンロードできる。
  3. 残したい設定とアプリのデータはクラウドバックアップで確認済み。ゴーグルの 設定 → 一般（版によっては システム → バックアップ）の「クラウドバックアップ」をオンにしておくと、アプリのデータと設定が保存される。初期から有効になっていることが多い。

文例（Teams・3 行）

借りているゴーグル 2 台、展示用のアカウントでログインし直すため、出荷時設定に戻します。
本体に入っているアプリやデータは消えますが、購入したものはアカウントに残ります。
残したい設定があれば、ゴーグルの設定のクラウドバックアップがオンになっているかだけ見ておいてください。

2.2 確かめる 2 点

確かめることなぜ・どう見分けるか
会社の組織管理（Meta Quest for Business）に入っていないか管理端末は初期設定が work.meta.com/device のコード入力画面で、Meta Horizon アプリは使わない確認済み。その場合は管理者だけが端末を解放でき、開発者モードも管理者の設定しだい二次情報。貸主に「初期設定でコードを入れる画面があったか」「自分の Meta Horizon アプリに台が出ているか」を聞く。管理端末なら、この手引きでは進めず、管理者に解放を頼む
貸主が所有者（メインのプロフィール）か貸主の Meta Horizon アプリの「デバイス」にその台が出ていれば所有者。所有者でない人が借りて又貸ししている台は、所有者に了解を取る

3. 先に試す: 追加プロフィールで開発者モードが出るか（10 分・壊さない）

ゴーグルを初期化せずに済む可能性を 10 分だけ確かめます。出なければ §4 へ進みます。この試しで貸主のデータが消えることはありません。

  1. 貸主のアカウントでログインしたままゴーグルを被り、右コントローラの Meta ボタンでメニューを出す。
  2. 左側の時計を選んでクイック設定を開き、右上の 設定 → プロフィール。
  3. 展示用アカウントのメールアドレスを入れて「リンクを送信」。リンクは 15 分で失効するので、すぐにスマートフォンでメールを開いて受け入れる確認済み。
  4. ゴーグルの中で展示用のプロフィールに切り替える。展示用アカウントでログインしたスマートフォンの Meta Horizon アプリに、その台が「デバイス」として出るか（出なければ「新しいデバイスを接続」でペアリングを試す）。
  5. アプリで ヘッドセット → ヘッドセット設定 を開き、「開発者モード」の項目が出てオンにできるか見る。
判定: 「開発者モード」が出てオンにできた → §6 の 2 以降（USB の許可へ）。出ない、または灰色でオンにできない → §4 へ。利用者の報告では追加プロフィール側のアプリには出ません二次情報。10 分を超えて粘らない。

試した追加プロフィールは、§4 でリセットすれば一緒に消えます。リセットしない場合は、貸主が自分のアプリの「プロフィールを管理」から外せます確認済み。

4. 出荷時設定にリセットする（ゴーグルのボタンだけで・5 分）

取り消せません確認済み。アカウント情報と、ダウンロード済みのゲームとコンテンツが本体から消えます。購入したものはアカウントに残ります。電池が 50% 以上あることを確かめてから行います。§2 の 3 点を貸主に伝えてから着手します。

貸主のスマートフォンもパスワードも要らない、本体のボタンだけの方法です（Meta Horizon アプリからもリセットできますが、貸主のアプリが要ります）。

  1. ゴーグルの電源を切る。左側の電源ボタンを長押しし、「電源を切る」を選ぶ。
  2. 電源ボタンと音量（−）ボタンを同時に押し続ける。起動画面（英語の文字メニュー）が出るまで離さない。出ないときは充電してからやり直す確認済み。電源ボタンはヘッドセット左側（Meta の初期設定ページ）。音量ボタンの位置は公式ページに記載が無いので、実機で先に確かめておく。
  3. 音量ボタンで「Factory Reset」（出荷時設定にリセット）に合わせ、電源ボタンで決定。
  4. 音量ボタンで「Yes」（はい）に合わせ、電源ボタンで決定。本体が消去されて再起動し、言語を選ぶ初期設定の画面になる。
関門 4: ゴーグルを被ると、言語を選ぶ初期設定の画面から始まる（ホーム画面に戻らない）。

この後に最初にログインした人が、その台の所有者になります確認済み。貸主のアカウントではなく、必ず展示用アカウントでログインします。

5. 展示用アカウントで初期設定する（Wi-Fi のある所で・15〜30 分）

Quest の準備 §4 と同じ手順です。借用機で気を付ける点だけ足します。

  1. ゴーグルの中の案内に従い、言語を選び、Wi-Fi に繋ぐ。
  2. コントローラを起こす（左はメニューボタン、右はホームボタン。両方を 2 秒長押しで白いライトが点滅）。
  3. 展示用アカウントでログインしたスマートフォンの Meta Horizon アプリで メニュー → デバイス → 「新しいデバイスを接続」→ Meta Quest Pro を選び、画面の指示に従ってペアリングする。貸主のスマートフォンは使わない。
  4. 初めてログインするときに Meta Horizon プロフィール（ゴーグルの中での名前）を作る。2 台目以降は同じアカウントなので、プロフィールはそのまま使う。
  5. ソフトウェアの更新が出たら、充電ドックに載せたまま完了まで待つ。初期化した台は更新が溜まっていることがあり、10〜30 分かかる。会場で始めない。
  6. 設定 → トラッキング で「ジェスチャーコントロールとボディトラッキング」（手の認識）をオンにする（展示で手だけの操作を使う場合）。
関門 5: ゴーグルを被るとホーム画面が出て、展示用アカウントのアプリの「デバイス」にその台が表示される。借用機 2 台と自前の 1 台で、アプリに 3 台が並ぶ。

6. 開発者モードを入れる（スマートフォン・2 分）

Quest の準備 §6 と同じです。開発者モードは台ごとに入れるので、3 台それぞれで行います。

  1. 展示用アカウントの Meta Horizon アプリで、ツールバーのヘッドセットのアイコン → その台 → ヘッドセット設定 → 開発者モード をオン。
  2. 項目が出ないときは、アプリを終了して開き直し、ゴーグルも再起動する。それでも出なければ §1 の登録と確認（関門 1）を見直す（§10）。

7. Mac と USB で繋いで許可する（インターネット不要・5 分）

Quest の準備 §7 と同じです。初期化した台は、以前の Mac への許可も消えているので、使う Mac ごとに許可を出し直します。

  1. ゴーグルを USB-C ケーブルで Mac に繋ぐ（データ対応のケーブル）。
  2. ゴーグルを被り、クイック設定 → 設定 → 開発者 で MTP 通知をオンにする。
  3. 「USB デバッグを許可しますか」で 「このコンピュータから常に許可」を選ぶ。出ないときはケーブルを挿し直してもう一度被る。
  4. Mac で確認する。 
    cd twinarm/discovery/koch
./scripts/start.sh check
    最後に ✓ ＜番号＞: 接続済み（adb 可・USB） とバッテリー残量が出れば完了。
関門 7: ./scripts/start.sh check に「接続済み」が出る。ここから先は VR のページ §3 の起動、境界（ガーディアン）の設定、位置合わせ。

9. 展示の後に戻す（返却）

展示用アカウントを本体から外して返すには、もう一度出荷時設定にリセットします。貸主は自分のアカウントでログインし直すと、再び所有者になります。

  1. §4 の手順でもう一度リセットする（電池 50% 以上）。展示用アカウント、開発者モード、USB の許可、位置合わせの保存は本体から消える。
  2. 言語を選ぶ画面のまま電源を切り、充電して返す。初期設定は貸主が自分のアカウントとスマートフォンで行う（最初にログインした人が所有者）。
  3. 展示用アカウントの Meta Horizon アプリの「デバイス」に残った台は、外しておく（任意）。
  4. 貸主に「初期化して返した。ダウンロードし直しが要る。購入物はアカウントに残っている」と一言添える。クラウドバックアップをオンにしていれば、設定とアプリのデータは復元される確認済み。
位置合わせの保存（永続アンカーと設定ファイル）は Mac 側の設定ファイルと本体の両方に関わります。返却の前に、次回のために設定ファイルを Mac に残しておきます（VR のページ §4）。

10. 困ったとき

症状確かめること・直し方
電源と音量（−）を押しても起動画面が出ない充電してからやり直す（Meta の案内）。ゴーグルが完全に電源オフになっているか。ボタンを離すのが早すぎないか
起動画面が出たが選べない音量（＋／−）で項目を移動し、電源ボタンで決定する。コントローラは使わない
リセット後の初期設定でコードを入力する画面が出た組織管理の台（§2.2）。進めずに貸主と管理者に相談する
アプリに「開発者モード」が出ない展示用アカウントでログインしたアプリか。その台とペアリングしたアプリか。開発者サイトで組織を作り、アカウントの確認と組織の確認が済んでいるか（関門 1）。アプリとゴーグルを再起動し、ゴーグルを最新にする
「開発者モード」をオンにすると「予期しないエラー」ゴーグルを Wi-Fi に繋いで更新してからやり直す（Meta の回答の例）
「USB デバッグを許可」が出ない初期化で以前の許可が消えている。ケーブルがデータ対応か。開発者モードがオンか。設定 → 開発者 の「MTP 通知」がオンか。ケーブルを挿し直してからゴーグルを被る
貸主が「購入したゲームが消えた」と言う本体から消えただけで、アカウントの購入物は残る。ストアからダウンロードし直す
追加プロフィールの招待リンクが開けない送信から 15 分で失効する。ゴーグルからもう一度送る
