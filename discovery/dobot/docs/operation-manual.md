# Dobot 実演 操作マニュアル（説明員向け）

版: 2026-10-19 ／ 関連: [要件定義書](requirements.md)・[導入手順](setup-manual.md)

## 0. 最初に: 腕が動く操作

次の操作で腕が動きます。腕の周りに手や物が無いことを確かめてから押してください。

- ランチャーの「実演を起動」「再起動」（ホームへ戻る）
- 実演画面の「ホーム」「往復（試運転）」「片付け」「ループ ×3」「自動ループ」、声や文字の指示
- ランチャーの「較正を確認」（ブロックを拾って中心へ置く）と「較正をやり直す」（ブロックを運んで 9 点を回る）

止めたいときは実演画面の **非常停止**（または入力欄の外で Esc）。動作中でも止まります。

## 1. 起動

1. Magician の電源を入れ、本体のキーを 2 秒長押し（LED が緑になればホーミング完了）
2. カメラと Magician の USB が Mac に挿さっていることを確認
3. `dobot/scripts` フォルダの **`start.command` をダブルクリック**（Terminal が開き、ブラウザにランチャーが出る）
4. ランチャーで **「実演を起動」** → 腕がホームへ動き、実演画面が開く（開かなければ「実演画面を開く」）
5. 実演画面に「声の準備ができました。」と出たら使える状態

ランチャーは http://127.0.0.1:8789 、実演画面は http://127.0.0.1:8790 です。

## 2. 実演画面の見方

上から順に:

| 場所 | 内容 |
| --- | --- |
| ヘッダー | 状態（待機／動作中／聞いています／非常停止）と時刻 |
| カメラ | 検出した物に色の枠と名前、ロボット座標（mm）。「x」が付いた物は腕が届かない場所 |
| 声 | マイクのボタン、聞き取った文、解釈、返事、カウントダウン |
| 操作 | 文字入力と、ホーム／往復／片付け／ループ／非常停止／停止解除／自動ループ |
| 記録 | 時刻つきの出来事 |
| 詳細 | 拾った数、fps、カメラ・ロボットの情報（折りたたみ） |

映像は左右反転して表示しています（来場者がロボットと向かい合う向き）。ロボットから見た「右」は画面の左です。

## 3. 声で指示する

1. **マイクのボタンを押したまま**（または入力欄の外で Space を押したまま）話し、**離す**
2. 「聞き取り」に文、「解釈」に例「赤いブロックを左へ」と出て、2 秒のカウントダウン後に実行
3. 今すぐ実行したいときは Enter、やめるときは Esc。聞き取りが少し違うなら、文を直して Enter

言い方の例:

| 言う | 動き |
| --- | --- |
| 赤いブロックを左に置いて／赤を左へ | 赤を左トレイへ |
| 青を奥に入れて | 青を奥の箱へ |
| 全部手前に入れて | 見えている物を全部、手前の箱へ（最大 12 個） |
| 片付けて／元に戻して | スタート台の外の物を全部スタート台へ |
| 止まって／ストップ | 非常停止 |
| 赤じゃなくて青を右に | 青を右へ（否定は最後の色が有効） |

置き場の呼び方: 右／左（トレイ）、手前／奥（箱）、スタート／元の場所。

よくある返事:

- 「赤いブロックはもう右にあります。」→ その物はすでにその置き場（半径 60 mm）の中。動かしたい物は置き場の外に置く
- 「右のトレイに空きがありません。」→ 置き場がいっぱい。片付けるか、別の置き場へ
- 「見えていますが、腕が届く範囲にありません。」→ 物をロボット側へ寄せる（画面の「x」印）
- 「赤いブロックが見つかりません。」→ カメラに映っていないか、色が判定から外れている（§6.4）

## 4. 文字とボタン

- 入力欄に文を入れて Enter（確認なしで実行）
- **往復（試運転）**: 作業域の中を 1 往復してホームへ。動作確認と非常停止の練習に
- **片付け**: スタート台へ全部戻す
- **ループ ×3**: 運ぶ → 戻す を 3 回
- **自動ループ**: 誰も触らない時間が続くと自動で運ぶ → 戻す を繰り返す（既定 OFF。熱の予算で自動的に休む）

## 5. 止める・非常停止・復帰

- 普通に止める: ランチャーの **「停止」**（腕がホームへ戻ってから切断）。そのあと電源を切る
- 緊急: 実演画面の **非常停止**（Esc）。腕はその場で止まり、ポンプも止まる
- 復帰: **停止解除** → **ホーム**。それから指示を出す
- 画面が固まった・反応しない: ランチャーの「再起動」。それでも駄目なら Terminal で Ctrl+C して `scripts/start.command` からやり直す

## 6. 調整（ランチャーから）

### 6.1 設定フォーム（保存 → 再起動で反映）

| 項目 | いつ変える |
| --- | --- |
| 速さ（%） | 脱調アラームが出る・物を落とす → 70。もっと速く → 100 が上限 |
| 退避の高さ z_safe | 運んでいる物が箱の縁に当たる → 大きく（40）。速くしたい → 小さく（20） |
| 吸着の待ち（秒） | 吸えずに落とす → 0.6 |
| 移動の補間 | 経路が曲がって何かをかすめる → movl（遅くなる） |
| 映像を左右反転 | 来場者の立ち位置に合わせる |
| 声の確認待ち（秒） | 来場者が戸惑うなら長く |
| Claude で解釈 | API キーがあるときだけ ON |

### 6.2 置き場を置き直したとき

ランチャーの **「置き場を調整」** → 画像に 5 つの丸が出る → 数字キー（1〜5）で選び、実物のトレイの真ん中をクリック → **s** で保存 → **q** で閉じる。実演は自動で止まるので、終わったら「実演を起動」。

### 6.3 カメラかロボットを動かしたとき（較正）

動かしていなければ不要（ランチャーの「較正: 日時・RMS・点数」を見る）。迷ったら **「較正を確認」**: 青ブロックを 1 個、カメラに見える所（トレイの外）に置いて押す → Terminal が開き、腕が拾って中心へ置き、ずれを測る（30 秒）。「使えます」ならそのまま。

やり直すとき: 机からトレイをどけ、青ブロックを 1 個用意 → **「較正をやり直す」** → Terminal が開き、腕が最初の点（手前右の隅）の上で止まる → **吸盤の真下にブロックを置いて Enter（1 回だけ）** → あとは腕がブロックを運んで 9 点を回る（約 1 分）。終わると RMS が出る（3 mm 以下で合格）。見えない・落としたときは聞いてくるので、吸盤の真下に置いて Enter。そのあと §6.2 で置き場も確認。

### 6.4 色が検出されないとき

照明や露出が変わると色の判定から外れます。開発者が `src/config.json` の `objects[].ranges` を調整します（[導入手順 §4.4](setup-manual.md)）。応急処置として、ブロックを影や反射の無い場所へ動かす。

### 6.5 高さがおかしいとき（押し付ける・届かない）

机や台を変えたときに起きます。[導入手順 §4.3](setup-manual.md) の手順で `z_pick`・`z_place` を測り直します。

## 7. 困ったとき

| 症状 | 見るところ・対処 |
| --- | --- |
| 「マイクが使えません」 | macOS のマイク許可（システム設定 → プライバシーとセキュリティ → マイク → Terminal）。許可後に再起動 |
| 押しても録音にならない | 「声の準備ができました」が出てから押す。初回はモデルの読み込みに数秒 |
| 聞き取りが違う | 文を直して Enter。騒がしければ文字入力 |
| 腕が途中で止まり「アラーム」 | 脱調（速すぎ・引っかかり）。停止解除 → ホーム。速さを 70 に |
| 「届きません」「作業域の外」 | 物や置き場を作業域（ロボットから 15〜30 cm）に入れる |
| 映像が出ない | カメラの USB、他のアプリ（Zoom 等）がカメラを掴んでいないか。再起動 |
| 画面が開かない | ブラウザで http://127.0.0.1:8789（ランチャー）、http://127.0.0.1:8790（実演） |
| ポートが使用中で起動しない | 前の実演が残っている。ランチャーの「停止」、または Terminal で `pkill -f dobot.demo` |

## 8. 終了

1. ランチャーの「停止」（腕がホームへ）
2. Terminal で Ctrl+C（ランチャー終了）
3. Magician の電源を切る
