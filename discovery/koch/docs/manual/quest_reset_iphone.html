借りた Quest Pro を初期化して開発者モードにする

iPhone と Meta Horizon アプリで進める手順。アプリで「開発者モードを利用できるのはデバイス所有者のみ」と出た台のためのものです。所有者を変える公式の方法は出荷時設定へのリセットだけで、リセットの後に最初にログインした人が所有者になります。

画面の図は模式図です。文言と並びはアプリと本体の版で少し違います。

今日の流れ（借用機 1 台あたり。更新の待ち時間を除いて約 40 分）

1貸主に一言2電池 50% 以上3リセット 5 分4初期設定 15〜30 分5更新6開発者登録（未了なら）7開発者モード 2 分8MTP 通知と USB の許可9Mac で check

Wi-Fi（会社か iPhone のテザリング）が要るのは 4〜7。8 と 9 はネット不要です。

1貸主に伝える1 分

「開発者モードは所有者のアカウントだけと出たので、ゴーグルを初期化して展示用アカウントで使います。本体の中のアプリと設定は消えますが、購入したものはアカウントに残ります。フェスの後にもう一度初期化して返します。」
  • 残したい設定があれば、本体の 設定 → 一般（版によっては システム → バックアップ）の「クラウドバックアップ」がオンかだけ見てもらう。多くは最初からオンです。
  • 初期設定のときに work.meta.com/device のコードを入れた台（組織管理の台）なら、管理者の設定が要るので先に貸主に聞く。

2電池と iPhone の準備5 分

  • ゴーグルの電池を 50% 以上にする（Meta の条件）。できれば充電しながら。
  • iPhone に App Store から Meta Horizon を入れ、展示専用のアカウントでログインしておく。Wi-Fi と Bluetooth をオン。
  • 貸主のアカウントで入った iPhone は使わない。

3出荷時設定にリセット（ゴーグルのボタンだけ）5 分

貸主のスマートフォンもパスワードも要りません。取り消せないので、1 と 2 を済ませてから。

  1. 電源を切る。左側の電源ボタンを長押しし「電源を切る」。
  2. 電源ボタンと音量（−）ボタンを同時に押し続ける。英語の文字メニューが出るまで離さない。出ないときは充電してからやり直す。
  3. 音量ボタンで Factory Reset に合わせ、電源ボタンで決定。
  4. 音量ボタンで Yes に合わせ、電源ボタンで決定。消去と再起動のあと、言語を選ぶ画面になる。
関門 3: 本体が消去されて再起動し、言語を選ぶ画面が出る。

4展示用アカウントで初期設定（iPhone でペアリング）15〜30 分

  1. ゴーグルで言語を選び、Wi-Fi に繋ぐ。
  2. コントローラを起こす。左はメニューボタン、右はホームボタンを 2 秒長押しして白いライトが点滅すれば準備完了。
  3. iPhone の Meta Horizon アプリで メニュー → デバイス → 新しいデバイスを接続 → Meta Quest Pro。ゴーグルに出る 5 桁のコードを入れる。
  4. ここでログインしたアカウントが所有者になる。必ず展示専用アカウント。
  5. 初めてなら Meta Horizon プロフィール（ゴーグルの中の名前）を作る。2 台目以降は同じプロフィールを使う。
関門 4: ゴーグルを被るとホーム画面が出て、アプリの「デバイス」に Meta Quest Pro が表示される。

5本体の更新10〜30 分

  • 更新が出たら、充電ドックか充電器に繋いだまま完了まで待つ。初期化した台は更新が溜まっていることがある。
  • 手で確かめる: ゴーグルの クイックコントロール → 設定 → 一般 → ソフトウェアのアップデート。
  • 会場では更新を始めない（Wi-Fi が無い）。前日までに済ませる。
  • 手だけで操作するなら、設定 → トラッキング → 「ジェスチャーコントロールとボディトラッキング」をオン。

6開発者登録（まだなら・1 回だけ）15〜30 分

開発者モードのスイッチは、開発者組織（チーム）に属し、確認の済んだアカウントにしか出ません。iPhone の Safari か PC で行います。

  1. developers.meta.com を開き、展示専用アカウントでログイン。
  2. 開発者ダッシュボードの Create New Team で組織（チーム）を作る。名前は自由。
  3. 確認（verification）の欄で、SMS の二段階認証か支払い方法（PayPal は不可）を登録する。SMS が届かなければ支払い方法に切り替える。
  4. 組織の確認（身分証・通常は数分）も済ませる。Meta のサポートは開発者モードの前提として求めた例があります。
関門 6: ダッシュボードに自分の組織が出て、確認が済んだ表示になる。

7開発者モードを入れる（iPhone のアプリ）2 分

ゴーグルの設定にはありません。アプリで入れます。ゴーグルは電源オン・Wi-Fi に繋いだままにします。

  1. アプリ下のツールバーのヘッドセットのアイコン（デバイス）をタップ。
  2. ペアリング済みの Meta Quest Pro（機種名と状態の項目）をタップ。
  3. ヘッドセットの絵の下の ヘッドセット設定 をタップ。
  4. 開発者モード をタップし、スイッチをオンにする。
項目が出ないとき: 6 の登録と確認が済んでいるか、同じアカウントでアプリにログインしているか。アプリを終了して開き直し、ゴーグルも再起動する。ゴーグルの更新が残っていないか。
関門 7: 開発者モードのスイッチがオンで、ゴーグルの 設定 に「開発者」の項目が現れる。

8MTP 通知をオンにして USB を許可（ゴーグル）5 分

アプリに USB の設定はありません。ここからはゴーグルと Mac だけで、ネットも要りません。

  1. Mac に adb を入れる（1 回だけ）。
    brew install --cask android-platform-tools
  2. ゴーグルを被り、クイック設定 → 設定（歯車）→ 開発者 で MTP 通知 をオン。
  3. データ対応の USB-C ケーブルでゴーグルを Mac に繋ぐ。
  4. ゴーグルの中に「USB デバッグを許可しますか」と出るので、「このコンピュータから常に許可」にチェックして許可。出ないときはケーブルを挿し直してもう一度被る。
  5. 許可は Mac とゴーグルの組ごと。別の Mac を使うときはその Mac でも出し直す。
関門 8: 拒否を押してしまったら、ケーブルを抜いてゴーグルを再起動し、繋ぎ直す。

9Mac で確かめる2 分

cd twinarm/discovery/koch
./start.sh check

最後に ✓ ＜番号＞: 接続済み（adb 可・USB） と電池残量が出れば完了。「未許可」なら 8 の許可をやり直す。「端末が見えません」ならケーブル（充電専用は不可）と開発者モード。

関門 9: check に「接続済み」。ここから VR の手引き §3 の起動（./start.sh vr）、境界の設定、位置合わせへ。

後フェスの後に戻す

  1. 3 の手順でもう一度出荷時設定にリセットする（電池 50% 以上）。展示用アカウント、開発者モード、USB の許可、位置合わせの保存が本体から消える。
  2. 言語を選ぶ画面のまま電源を切り、充電して返す。初期設定は貸主が自分のアカウントと iPhone で行う。
