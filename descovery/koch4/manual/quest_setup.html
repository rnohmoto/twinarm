Quest Pro の準備

Meta アカウントを作るところから、ゴーグルを USB で Mac に繋いで VR のページを開けるようにするところまでの手引きです。最初に 1 回だけ行います。

開発者の登録ではアカウントの確認があり、日数がかかることがあります。本番の 1〜2 週間前に済ませます。所要時間は、確認の待ち時間を除いて 30〜40 分ほどです。

0. 流れ

1. 用意する物

2. Meta アカウントを作る

ゴーグルを使うには Meta アカウントが必須です。Facebook や Instagram のアカウントは要りません。

  1. パソコンかスマートフォンのブラウザで auth.meta.com を開く。「ログインまたはアカウントを作成」という画面が出る。
  2. 「携帯電話番号またはメールアドレスを使用」を選ぶ（Facebook・Instagram でログイン、は選ばない）。
  3. 展示専用にするメールアドレスを入力して「次へ」。
  4. この先は画面の案内に従う。メールに届く確認コードの入力、名前、生年月日、パスワードの設定を求められる。生年月日は 18 歳以上になる実際の日付を入れる（開発者の登録は 18 歳以上が条件）。
  5. パスワードと、確認に使ったメールアドレスを、担当者どうしで決めた場所に記録する。
なぜ展示専用のアカウントにするか: Meta の規約では、アカウントのパスワードを他人と共有したり、アカウントを譲ったりすることはできません。個人のアカウントで会社のゴーグルを設定すると、担当が替わったときに引き継げなくなります。会社のメールアドレスで 1 つ作り、管理する人を決めておくのが安全です。
関門 2: auth.meta.com に、作ったメールアドレスとパスワードでログインできる。

3. スマートフォンに Meta Horizon アプリを入れる

  1. App Store か Google Play で「Meta Horizon」を入れる。
  2. アプリを開き、§2 で作ったアカウントでログインする。
  3. スマートフォンの Wi-Fi と Bluetooth をオンにしておく（初期設定に必要）。

4. ゴーグルの初期設定とペアリング

  1. 電源を入れる。ヘッドセット左側の電源ボタンを 3 秒、チャイムが鳴るまで長押しする。
  2. コントローラを起こす。左はメニューボタン、右はホームボタンを押す。両方を 2 秒長押しして、白いライトが点滅すれば準備完了。
  3. ゴーグルの中の案内に従う。言語を選び、Wi-Fi に繋ぎ、頭に合わせて締め具合と目の幅を調整する。
  4. スマートフォンとペアリングする。ゴーグルを外し、Meta Horizon アプリで メニュー → デバイス → 「新しいデバイスを接続」→ Meta Quest Pro を選び、画面の指示に従う。
  5. プロフィールを作る。初めてログインするときに Meta Horizon プロフィール（ゴーグルの中での名前）を作る。ユーザー名は 3〜30 文字。
  6. 更新を済ませる。ソフトウェアの更新が出たら、充電ドックに載せたまま完了まで待つ。

充電ドックは付属の 45W 電源アダプターで使います。それより小さい充電器ではドックに電気が届きません。USB-C ケーブルで直接充電するときは、前面のガラスを守るため付属の保護カバーを付けます。

関門 4: ゴーグルを被るとホーム画面が出て、Meta Horizon アプリの「デバイス」に Meta Quest Pro が表示される。

5. 開発者の登録（組織を作り、アカウントを確認する）

USB で Mac から操作できるようにするには、ゴーグルの「開発者モード」が要り、その前提として開発者の登録をします。費用はかかりません。

  1. パソコンのブラウザで Meta の開発者サイトを開き、§2 のアカウントでログインする。
  2. 組織（チーム）を作る。開発者ダッシュボードの「Create New Team」のページで、組織の名前などを入力する。名前は自由に決めてよい（例: 会社名と部署名）。
  3. アカウントを確認する。ダッシュボードの確認（verification）の欄で、次のどちらかを行う。
    • 携帯電話の番号を登録し、SMS で二段階認証を設定する
    • 支払い方法（クレジットカードなど）を登録する。PayPal は不可
  4. §6 でスイッチが出ない場合だけ、組織の確認（身分証を使う管理者の確認。通常は数分）も行う。Meta の文書では、これはアプリを公開するための手続きですが、開発者モードの条件として求められた例があります。
関門 5: 開発者ダッシュボードに自分の組織が表示され、アカウントの確認が済んだ表示になっている。

6. 開発者モードを入れる

  1. スマートフォンの Meta Horizon アプリを開く。
  2. ツールバーのヘッドセットのアイコンをタップする。
  3. ペアリング済みのヘッドセット（機種名と状態が出ている項目）をタップする。
  4. ヘッドセットの絵の下の「ヘッドセット設定」をタップする。
  5. 「開発者モード」をタップし、スイッチをオンにする。

「開発者モード」の項目が見当たらないときは、アプリを一度終了して開き直し、ゴーグルも再起動します。それでも出なければ §9。

7. Mac と USB で繋いで許可する

  1. Mac に接続用のツール（adb）を入れる。 
    brew install --cask android-platform-tools
  2. ゴーグルを USB-C ケーブルで Mac に繋ぐ。
  3. ゴーグルを被る。「USB デバッグを許可しますか」と出るので、「このコンピュータから常に許可」を選ぶ。予備の Mac がある場合は、その Mac でも同じ許可を出しておく。
  4. Mac で確認する。 
    cd twinarm/descovery
./koch4/start.sh check
    最後に ✓ ＜番号＞: 接続済み（adb 可・USB） とバッテリー残量が出れば完了。
関門 7: ./koch4/start.sh check に「接続済み」が出る。ここまで済めば VR のページ §3 の起動に進める。

8. 展示の前に済ませること

  • ゴーグルのソフトウェア更新を前日までに済ませる。当日はインターネットに繋がないので、更新は始まりません。
  • 会場で、ゴーグルの境界（ガーディアン）を設定する。その後に 位置合わせを行う。
  • ゴーグルとコントローラを満充電にする。電源の組み方は VR のページ §8。
  • 来場者に着けてもらう場合は、使い方と注意を先に説明し、1 人ごとに顔に当たる部分を拭く。

9. 困ったとき

症状確かめること・直し方
アプリに「開発者モード」が出ない開発者サイトで組織を作ったか。アカウントの確認（SMS か支払い方法）が済んでいるか。アプリとゴーグルを再起動する。ゴーグルのソフトウェアを最新にする。それでも出なければ、組織の確認（身分証）を行う
SMS が届かない支払い方法の登録に切り替える
ペアリングで機器が見つからないスマートフォンの Bluetooth と Wi-Fi がオンか。ゴーグルの電源。スマートフォンをゴーグルの近くに置く
「USB デバッグを許可」が出ないケーブルがデータ対応か。開発者モードがオンか。ケーブルを挿し直してからゴーグルを被る。誤って拒否したときは、ケーブルを抜いてゴーグルを再起動し、繋ぎ直す
check に「未許可」と出るゴーグルを被り、許可の画面で「常に許可」を選ぶ
check に「adb が見つかりません」と出る§7 の 1 を行う。Meta Quest Developer Hub を入れている場合は、その中の adb でもよい
