# Dobot Magician 画像認識ピック＆プレース実演 — 要件定義書

版: 2026-10-19 ／ 対象: `dobot/` 一式 ／ 関連: [操作マニュアル](operation-manual.md)・[導入手順](setup-manual.md)・[作業記録](worklog-2026-10.md)

## 1. 目的

展示（ラーニングフェス 2026-10-26〜27 ほか）で、来場者の声や文字の指示に応じて、机の上の色ブロックをカメラで見つけ、
Dobot Magician が拾って指定の置き場へ運ぶ実演を、**説明員が 1 人で、ロボットの専門知識なしに、安全に**運用できること。

## 2. 利用者と場面

| 利用者 | すること | 前提知識 |
| --- | --- | --- |
| 来場者 | マイクのボタンを押して話す／文字で指示する／画面で結果を見る | なし |
| 説明員 | 起動・停止・非常停止・片付け・簡単な調整（速さ、置き場、較正のやり直し） | マニュアルのみ |
| 開発者 | 検出や動作の調整、コードの保守、別の机への移設 | Python・このリポジトリ |

## 3. システム構成

### 3.1 機材

| 機材 | 仕様・設定 |
| --- | --- |
| ロボット | Dobot Magician（吸盤）。USB シリアル（CH9102、macOS 12 以降は追加ドライバ不要）。電源投入後に本体キー 2 秒長押しでホーミング |
| カメラ | Logicool C922、机の真上に固定（俯瞰）。1280×720・30 fps。露出・フォーカスは Logi Options+ で固定、WB は自動 |
| PC | macOS（Apple Silicon で確認）。Python 3.13 は uv が取得。ネットは初回の準備のみ |
| 対象物 | 木のブロック 4 色（赤・緑・青・黄、厚み 16 mm、長辺 約 75 mm）。ボールは設定済みだが未使用 |
| 置き場 | 机の上の 5 か所（右トレイ・左トレイ・手前の箱・奥の箱・スタート台）。実物のトレイは任意 |

## 4. 機能要件

### F1 指示の入力
- F1.1 声: ボタン（または Space）を押している間だけ録音し、離すと聞き取る。聞き取った文と解釈を表示し、既定 2 秒後に実行。Enter で即実行、Esc で取り消し。聞き取りの文は手で直して Enter できる
- F1.2 文字: 入力欄の文を即実行（例「赤いブロックを左に置いて」「全部手前に入れて」「片付けて」）
- F1.3 ボタン: ホーム／往復（試運転）／片付け（元に戻す）／ループ ×3／非常停止／停止解除／自動ループ ON/OFF
- F1.4 解釈は日本語ルール（色・置き場の別名、否定「赤じゃなくて青」、曖昧なら確認）。Claude は任意

### F2 物体の認識
- F2.1 色の範囲（HSV）と形（面積・縦横比・円形度）で、4 色ブロックとボールを検出する。範囲は `src/config.json` で調整できる。球の円形度は輪郭の凸包で測る（ディンプル・縁の影で欠けても丸と分かる）
- F2.2 画像座標をホモグラフィでロボット座標（mm）に変換し、各物の大きさ（長辺 mm）も推定する
- F2.3 作業域の外にある物は「見えているが届かない」と表示する

### F3 ピック＆プレース
- F3.1 退避高さ（z_safe）で移動 → 物の上面へ直線で降下 → 吸着 → 退避 → 置き場へ移動 → 直線で降下 → 離す。拾う高さも置く高さも物ごと（`objects[].z_pick` / `z_place`。置き場に `z_place` があればそれが優先）: ブロック 16 mm とゴルフボール 43 mm では置く高さが 27 mm 違う
- F3.2 置く位置は、スロット → 置き場の中心 → 置き場の半径内（中心に近い順）の順で、**カメラに見えている物に重ならない**最初の場所（距離 ≥ 両者の長辺の半分＋8 mm）。作業域の外は使わない
- F3.3 置き場に空きが無ければ拾わずに「〜に空きがありません」と返す。対象がすでにその置き場にあれば動かさず「もう〜にあります」
- F3.4 「全部」は最大 12 個。片付けはスタート台の外の物をすべてスタート台へ

### F4 安全
- F4.1 腕が動くのは、実演の起動（ホームへ）、ボタン・指示の実行、較正ツール（`--drive`）だけ。どれも人の明示操作で始まる
- F4.2 作業域ガード（x 150〜300、y ±150、z −80〜120、到達半径 140〜315 mm）を全ての移動で実行前に確認する
- F4.3 非常停止は動作中でも効く（ForceStop → キュー消去 → ポンプ停止）。復帰は「停止解除」→「ホーム」
- F4.4 連続運転の上限（熱の予算: 10 分あたり 240 秒、1 時間あたり 20 サイクル）を超えると自動動作を止める
- F4.5 アラーム（脱調など）は移動前と移動中に読み、出たら止めて理由を表示する

### F5 表示（パネル）
- F5.1 上から: カメラ映像（検出枠つき、左右反転可）→ マイク → 操作 → 記録。状態（待機／動作中／非常停止）はヘッダー
- F5.2 映像は 15 fps で、腕が動いている間も更新される
- F5.3 聞き取り・解釈・返事・最後の動作・エラーを表示する

### F6 設定・較正の道具
- F6.1 較正: ブロックを 1 個置くだけで、ロボットが自分で持ち運んで 3×3 の格子（または中心＋四隅の 5 点）を回り、各点で置いた位置をカメラで読む（`dobot-calibrate --carry`）。拾い損ねは自動で拾い直し、見えない・落とした点は人に聞く。残差 8 mm 超の点は外す。RMS と前回との差を表示し、途中で落ちても点が残る。確認モード（`--verify`、30 秒）で、やり直しが要るか（ずれ 3 mm 以下で合格）を判定する。各点で人が置く `--drive` は予備
- F6.2 置き場: カメラ画像をクリックして決める（`dobot-zones`）。スロットが作業域からはみ出す位置は拒否する
- F6.3 高さ: 吸盤を当てた姿勢を読んで決める（`dobot-check-robot`、ウィザード 5〜6 番）
- F6.4 ランチャーの設定フォーム: 速さ、退避高さ、吸着待ち、補間、映像の反転、fps、確認待ち、Claude の ON/OFF。保存前に検証し、保存前の設定はバックアップする

### F7 運用
- F7.1 起動は 1 操作（`scripts/start.command` のダブルクリック、または `./scripts/start.sh`）。停止は画面のボタン
- F7.2 別の Mac へは `git clone` → `scripts/setup.command` の 1 回で準備できる。同じ机なら較正もそのまま使える
- F7.3 実演のログ（jsonl）と作業記録を `logs/` に残す

## 6. 制約と前提

- Magician の位置決め精度は数 mm。吸盤 φ20 mm に対してブロックは 75×27 mm なので、3 mm 程度のずれは吸着できる
- 色の判定は照明に依存する。照明や露出が変わったら `objects[].ranges` を調整する（ウィザード 7 番で確認）
- カメラかロボットを動かしたら較正（5 分）が必要。トレイを置き直したら置き場の設定（1 分）が必要
- 声は静かな環境を想定（faster-whisper small、日本語）。騒がしい会場では文字入力を併用する
- Windows は `scripts\start.bat` があるが未検証
