卓上ロボット 当日の手引き

Dobot Magician（吸盤）・俯瞰カメラ C922・Mac D。2026-10-26 版。会場で触るのは「確認 → 必要なら較正 → 置き場 → 1 回動かす」の 4 つ。細かいことは docs/fest-checklist-261026.md と docs/HANDOFF.md。

1電源とホーミング電源 ON → 本体キー 2 秒長押し → LED が緑。電源を入れるたびに必ず
2起動scripts/start.command をダブルクリック → ランチャー（ブラウザ）
3較正を確認（30 秒）青ブロックを見える所に 1 個置いて「較正を確認」。「使えます」ならそのまま
4置き場と 1 回トレイを置いたら「置き場を調整」→「実演を起動」→ 往復 → 文字で 1 回 → 声で 1 回

1. 新しい版を Mac に入れる（最初に 1 回）

10/21 に置き場所が変わりました。旧: twinarm-main/dobot/（設定 config.json・起動 start.command）→ 新: discovery/dobot/（設定 src/config.json・起動 scripts/start.command）。デスクトップのエイリアスは旧の start.command を指しているので、作り直します。

A. フォルダが git のクローンのとき（Terminal で git status が通る）

cd ~/twinarm            # 実際のフォルダへ
git fetch origin
git checkout ms/feat/dobot-calibrate-carry-261026
cd discovery/dobot
uv sync --extra voice --extra llm   # 1 回。声と Claude の分（約 150 MB・ネットが要る）
./scripts/start.sh check            # 「passed」が出れば入っている。腕は動かない

旧の dobot/config.json を手で直していた（ポート・置き場・高さ）なら、その値を src/config.json に写す。ポートは ls /dev/cu.usbserial-*。

B. zip で持ってきたとき（git が無い）

GitHub の twinarm → Branches → ms/feat/dobot-calibrate-carry-261026 → Code → Download ZIP。展開して discovery/dobot/scripts/setup.command をダブルクリック（uv・依存・音声モデル・テストまで自動）。終わったら scripts/start.command のエイリアスをデスクトップへ。

どちらの場合も、以前の assets/homography.json（較正）は新しい版にも入っています（10/19・9 点・RMS 3.10 mm）。カメラとロボットを動かしていなければそのまま使えます。

1.5 机と壁を教える（巻尺で 3 つ・1 分）

貸与の長机は 1800 × 600 mm（什器精査 9/24・半円構想 9/30）。右が壁で狭いときは、基部の中心から測った 3 つの距離をランチャーの設定に入れると、腕はそこから 40 mm 内側までしか行きません（較正の格子・置き場・ジョグも同じ箱）。空欄は制限なし。

2. 較正: ブロックを 1 回置くだけ

較正が要るのはカメラかロボットを動かしたときだけ。迷ったら「較正を確認」（30 秒）。やり直すときは「較正をやり直す」（約 1 分）。

ボタン前に用意するもの腕の動き結果の見方
較正を確認青ブロック 1 個をカメラに見える所（トレイの外）に置く拾って中心へ置き、置いた位置を読む（30 秒）「使えます: ずれ x mm」→ 何もしない。「拾えませんでした」「ずれ > 3 mm」→ やり直す
較正をやり直すトレイをどける。青ブロック 1 個最初の点の上 8 mm で止まる → 真下に置いて Enter → 9 点を回る（約 1 分）RMS 3 mm 以下で合格。超えたらカメラの固定（AF・露出）と置き方を見てもう 1 回

3. 白い机の白いゴルフボール

色では見つかりません（机も白）。この版は「丸い縁の影」で見つけます。上から見た球は、中心が明るく、縁に向かって暗くなり、片側に影が落ちます。平らな白い物（紙・ブロックの上面）は中心と縁が同じ明るさなので、球と区別できます。

見る所やること
見つかるかボールを 1 個置いて、実演画面に golf_ball の枠が付くか。付かなければ src/config.json の golf_ball を順に: rim_contrast 10 → 6、min_limb_drop 6 → 3、hough_param2 28 → 20。誤検出（無い所に枠）なら逆に上げる
照明真上からの一灯より、少し斜めからの光の方が縁の影が出て見つけやすい。机の上に白い丸い物（カップ・コースター）を置かない
高さz_pick −30.5／z_place −27.5 は机 −72.2 からの計算値。1 回だけ吸盤をボールの上面に当てて uv run dobot-check-robot --config src/config.json の z を読み、−1 を z_pick、+3 を z_place に（dobot-setup --from 6 なら自動）
吸えるかディンプルで密着が不確実（公開事例なし）。10 回試して 9 回吸えなければ「展示のみ」にして卓球ボールへ。次の手は柔らかい大径の吸盤
端のずれ較正はブロックの上面（16 mm）で取り、ボールの赤道は 21 mm。カメラの真下から 30 cm 離れると 3 mm ほど外側に見える。ボールはカメラの真下 20 cm 以内に置く

5. 困ったとき

症状対処
腕が止まり「脱調」のアラーム腕の周りを空けて本体キー 2 秒長押し（ホーミング・J1 が左右に振れる・LED が緑まで）→ 停止解除 → ホーム。画面の「ホーム」だけでは直らない（座標へ動くだけで基準を取り直さない）。繰り返すなら速さを 70 に
「届きません」「限界」物や置き場をロボットから 15〜30 cm の中へ → 停止解除 → ホーム（自動で解除される）
「拾えませんでした」が続く吸着の待ちを 0.6 に。ブロックの上面の汚れ。z_pick が上面 −1 か（dobot-setup --from 6）
較正の RMS が 3 mm 超Logi Options+ の AF・露出が自動に戻っていないか。三脚の揺れ。ブロックが真下からずれて置かれた → もう 1 回
色が拾えない照明が変わった。ブロックを影の無い所へ。dobot-setup --from 7 で枠を見ながら objects[].ranges
画面が固まる・ポート使用中ランチャー「再起動」。駄目なら Terminal で Ctrl+C → start.command。残っていれば pkill -f dobot.demo
終わるとき: ランチャー「停止」（腕がホームへ）→ Terminal で Ctrl+C → 電源 OFF。

初めて実機で動くもの（結果を HANDOFF に書く）: ①較正を確認 ②較正をやり直す（1 回置くだけで回り切るか・RMS・秒数）③ゴルフボールの枠と吸着 10 回 ④20 サイクル連続。
