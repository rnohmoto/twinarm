# manual/img — 写真スロット

`manual/index.html` はここに置いた写真を同じファイル名で表示する（無いときは「未撮影」枠が出る）。
初期設定をしながら、下の表の順に撮ってこのフォルダへ入れる。横長・1600px 幅程度・JPEG で十分。

| ファイル名 | 何を撮るか | 撮り方の注意 |
|---|---|---|
| `01_magician_overview.jpg` | Magician 本体の全景（エンドエフェクタを付けた状態） | 軸数と制御器の有無が分かる角度（機種の判定に使う） |
| `02_rear_ports.jpg` | 本体背面の電源・USB・スイッチ | ケーブルを挿した状態で |
| `03_homing_led.jpg` | ホーミング後の LED（緑） | 本体キーとセットで |
| `04_camera_rig.jpg` | 俯瞰カメラの取り付け（アーム／スタンドと高さ） | メジャーを写して高さ 45cm が分かるように |
| `05_camera_view.jpg` | `check_camera.py` が保存したスナップショット（`logs/camera_check_*.jpg`をコピー） | 作業域全体と 4 隅のマーカーが入っていること |
| `06_markers.jpg` | 机の四隅に貼った ArUco と吸盤先端を合わせているところ | マーカーの ID 番号が読めるように |
| `07_objects_zones.jpg` | 対象物（立方体・卓球ボール・消しゴム）と置き場（トレイ）の配置 | 真上から |
| `08_first_pick.jpg` | 最初のピック成功の瞬間 | 吸着中の手先が分かるように |
| `09_pc_setup.jpg` | PC 画面（`main.py --tune` の検出枠） | スクリーンショットで可 |
| `10_estop.jpg` | 非常停止（電源スイッチの位置）と仕切り | 説明員向け |
